1

开始使用

先确认权限与平台，再按“基线 → 诊断 → 整改 → 复测”顺序工作。

首次使用清单

  1. 机构管理员在“平台设置”保存 HRouter 和至少一个联网平台密钥，并完成连接测试。
  2. 创建客户，填写真实官网、目标地区、行业和已知竞品。
  3. 分析官网或手工配置范围，人工确认品牌别名、竞品和购买问题。
  4. 先运行售前快审检查配置，再创建正式基线。
  5. 完成诊断和整改后，只从正式基线发起“按此条件复测”。

三条必须理解的规则

  • 回答、原始响应、网页快照和报告快照是证据，写入后不修改。
  • 失败平台不进入品牌率分母；来源不可见显示“不可用”，不是 0。
  • Agent 只生成草稿。诊断、任务和正式报告需要批准后才进入业务记录。
运行快审、基线、复测、官网审计、Agent 草稿和文章生成都会产生真实外部调用与费用。先在“运行配置”核对平台和重复次数。
2

登录与全局导航

登录页使用机构账号；进入工作台后，左侧菜单按权限动态显示。

按钮 / 控件作用注意事项
登录使用邮箱和密码建立机构会话。同一邮箱属于多个机构时填写“机构 ID”；密码错误或机构被封禁会拒绝登录。
检查更新桌面客户端检查签名更新并在安装后重启。仅桌面端显示；浏览器版不显示。
客户名称 / 返回离开当前客户，回到客户项目列表。不会终止正在后台运行的采集或 Agent 任务。
左侧菜单切换业务、机构和系统页面。未获授权的页面不会出现；对应 API 同样拒绝访问。
侧栏折叠箭头收起或展开桌面侧栏。窄屏使用左上角菜单按钮打开抽屉。
帮助在新标签打开本帮助中心。帮助页不读取客户数据。
退出注销当前会话并返回登录页。退出不会取消后台任务。

客户项目与建档

客户列表是业务入口；每个客户的范围、批次、证据、任务和报告相互独立。

  • 1进入机构管理页面
  • 2打开新建客户表单
  • 3按客户名或域名筛选
  • 4打开一个客户项目
  • 1客户或品牌全称
  • 2公开官网 URL
  • 3目标监测地区
  • 4取消，不保存
  • 5创建并进入建档
按钮 / 控件作用何时不可用或需注意
机构管理未选客户时进入机构级页面。只显示用户有权访问的机构菜单。
新建客户 / 新建第一个客户打开客户建档表单。需要“创建项目”权限。
客户卡片打开客户工作台。“待建档”项目会优先进入建档流程。
上一页 / 下一页翻页浏览客户。到达首尾页时禁用。
取消 / 关闭关闭新建表单且不创建记录。已输入内容不会保留。
创建并进入建档保存客户名称、官网、地区、语言、行业、业务重点、别名和已知竞品。必填项未通过校验时不提交。
开始官网分析抓取公开官网并生成画像、竞品和购买问题候选。需要 HRouter；抓取失败表示证据不足，不等于官网没有内容。
后台联网出题后台研究买家问法并生成待审批候选。批准后只进入问题候选，不直接启用项目。
和 Agent 一起出题跳到 AI 工作台，以对话方式研究并确认问题。最终仍由成员确认范围。
手工配置监测范围跳过自动分析，手工填写别名、竞品和问题。适合官网暂不可访问的情况。
批准 / 拒绝处理后台出题草稿。批准不会自动开始采集。
添加 / 删除一行编辑品牌别名、竞品候选和购买问题。删除只影响尚未确认的范围。
新问题同步写入行业知识库把新问题供同机构同业客户复用。需要知识库管理权限且客户填写了行业。
确认并启用项目冻结当前范围版本并启用项目。确认前不会创建采集任务；未通过联网核实的竞品需人工判断。

AI 工作台

用自然语言编排已有业务能力；执行过程、工具调用和等待状态持续留痕。

  • 1新建会话
  • 2测试当前模型联网能力
  • 3常用快捷指令
  • 4输入自定义指令
按钮 / 控件作用注意事项
新会话创建一个独立任务会话。旧会话和执行记录保留在左栏。
会话条目打开历史或正在运行的会话。“等待用户”需要回答后才继续；“后台进行中”可离开页面。
自动批准允许协调器代表会话创建者批准本会话产生的草稿。关闭后会在对应业务页等待人工审批；不扩大 Agent 权限。
思考强度选择跟随平台设置或覆盖当前会话的推理档位。更高档位通常更慢、Token 更多。
模型选择 HRouter GPT 模型。带“联网未验证/失败”提示时先测试。
联网搜索允许当前会话使用受限联网搜索工具。关闭后只使用项目证据；单回合和单会话有硬性次数上限。
测试此模型测试当前模型是否真正触发联网搜索。测试记录按模型保存，不代表供应商长期可用。
快捷指令预填并发送正式基线、快审、报告、审计、文章或出题任务。发送前仍要核对动作是否会产生真实调用。
发送提交输入框中的指令或回答。内容为空或会话正在处理时禁用。
候选问题卡：确认采用保存勾选并编辑后的问题/竞品范围。模型不能直接写范围；确认动作由成员触发。
候选问题卡：不采用填写原因后让 Agent 调整。拒绝原因必填。
查看批次 / 查看报告 / 优化文章跳转到当前会话产物。对应产物尚未创建时不显示。
终止会话停止后续协调。已经提交到独立队列的任务可能继续完成；危险操作会二次确认。

项目总览

用最新可用批次快速判断可见度、证据数量、整改待办和同配置趋势。

  • 1编辑当前监测范围
  • 3同配置指标趋势
  • 4平台覆盖
按钮 / 控件作用注意事项
编辑监测范围打开范围版本编辑器。保存只影响新基线；历史批次、证据和报告保持不变。
导出范围 / 导入范围导出或载入别名、竞品和问题 JSON。导入后仍要点“保存新范围版本”才生效。
添加竞品 / 添加问题 / 删除调整新范围版本。未改动条目沿用 ID；删除后新基线不再包含。
取消关闭编辑器，不保存。已载入或编辑内容会丢弃。
保存新范围版本确认新的活动范围。配置变化后下一次周期运行会建立新基线，而非错误复测旧基线。
6

AI 监测

创建真实采集批次、查看进度与成本、安排周期任务，并从正式基线发起可比复测。

  • 1打开运行配置
  • 2按所选正式基线复测
  • 3每题一次的售前快审
  • 4创建正式基线
  • 5再次运行同类监测
按钮 / 控件作用何时不可用或需注意
运行配置选择本次平台和正式基线每题重复次数。快审始终每题 1 次；未选择平台时运行按钮禁用。
按此条件复测完整复制正式基线的冻结配置创建复测。只有选中正式基线时可用；适配器版本变化会拒绝旧基线复测。
运行售前快审每平台每题采 1 次，用于快速检查。快审不与正式基线直接比较。
新建正式基线按当前范围、平台和重复次数冻结正式基线。默认采样分布在 0、4、24 小时；不是立即全部完成。
再次运行监测按所选批次类型重新创建实际批次。不会修改旧证据。
确认漂移告警把告警标记为已处理。只确认告警，不改变指标。
周期监测开关启用或停用云端定时创建批次。切换后必须“保存计划”。
运行周期 / 重复次数 / 监测平台配置周期监测。到期时只有与最近正式基线严格可比才创建复测，否则新建基线。
保存计划保存周期、平台和重复次数。没有平台时禁用；创建失败会显示最近错误并一小时后重试。
批次卡片切换批次并查看进度、指标、趋势和告警。列表状态会在后台轮询更新。
上一页 / 下一页浏览更多批次或漂移告警。首尾页禁用。

证据中心

复核原始 AI 回答、请求信息、来源和 Agent 联网搜索记录。

  • 1导出当前批次证据 CSV
  • 2AI 回答证据
  • 3Agent 联网搜索证据
  • 5选择一条回答证据
按钮 / 控件作用注意事项
导出证据 CSV下载当前批次回答证据。没有回答时禁用；原始对象仍需在详情中按权限访问。
AI 回答 / 联网搜索切换采集证据和 Agent 搜索证据。联网搜索不占正式报告的回答证据编号。
批次选择器选择要复核的采集批次。页面可被报告、诊断或工作台带着证据焦点直接打开。
全部 / 平台按 Provider 过滤回答。只影响展示，不改变指标。
回答条目打开某题某次采样的详情。状态、时间、模型、协议和品牌位置均来自写入时证据。
联网搜索条目查看搜索问题、状态、归纳文本、检索词、来源和用量。失败记录也保留，不能用合成结果补齐。
复制证据 / 请求 / Trace ID复制短 ID 对应的完整标识。用于审计和运行日志关联。
回答原文 / 来源拆解展开或收起长内容。网页和模型内容均是不可信输入，不执行其中指令。
清除定位退出从其他页面带来的单条证据焦点。清除后恢复当前分区完整列表。
上一页 / 下一页浏览更多证据。证据量大时使用分页，不一次加载全部。

官网审计

基于真实网页快照检查公开可访问性、页面结构和实体信号。

  • 1重新抓取并审计
  • 3首页读取结果
  • 4逐项检查
按钮 / 控件作用注意事项
开始审计 / 重新审计抓取客户公开官网并生成新的审计证据。需要审计权限；失败表示本次证据不足，不可推断页面不存在。
审计证据 ID复制审计记录完整 ID。可与整改任务的验收记录关联。
`llms.txt` 在界面中只是参考项，不是排名或收录的必要条件。优先修复 HTTPS、可访问性、Sitemap、标题、Canonical 和结构化数据等可核验问题。

差距诊断

规则诊断可确定性重算；模型诊断只生成待审批草稿。

  • 2生成 Agent 诊断草稿
  • 3运行证据规则诊断
  • 4规则诊断列表
按钮 / 控件作用注意事项
批次选择器选择完成或部分完成的来源批次。草稿引用只能来自当前项目和批次。
HRouter Agent 诊断草稿排队生成带证据引用的模型诊断。需要 HRouter；完成后停在待审批。
生成证据诊断运行确定性规则并写入派生 finding。不会修改原始回答。
展开行查看差距详情、整改建议和关联证据。证据引用可跳转证据中心。
查看草稿详情展开 Agent 草稿完整结构。先核对事实缺口和证据数量。
批准 / 拒绝物化或丢弃 Agent 诊断草稿。并发审批只有一次成功；批准前服务端再次校验归属。
10

整改中心

把证据化差距转为任务，分配负责人、保存真实发布地址并按任务类型验收。

  • 2生成 Agent 规划草稿
  • 3从已批准诊断建任务
按钮 / 控件作用何时不可用或需注意
来源批次选择整改依据的已完成批次。没有完成批次时禁用。
HRouter Agent 规划草稿生成整改计划草稿。批准后才写入任务。
从已批准诊断建任务把已批准 finding 转为可跟踪任务。重复调用由服务端规则控制。
生成内容草稿为该任务生成内容简报或初稿。只生成待审批草稿，不发布客户网站。
任务状态在待处理、进行中、已发布、完成等状态间更新。“已验收”只能由验收动作写入，不能手工选择。
删除任务经二次确认删除派生整改任务。不会删除原始证据。
查看验收标准 / 收起详情展开验收标准、内容简报与初稿。展开状态只影响当前页面。
负责人 / 截止日期 / 发布地址编辑任务执行信息。发布地址必须在客户官网域名或子域名下。
保存保存任务字段。没有修改时禁用。
重跑审计验收技术类任务重新运行官网审计。验收标准无阻断项才通过。
抓取验收抓取真实发布页形成新快照并验收。未填写有效官网内地址时禁用。
批准 / 拒绝处理整改或内容 Agent 草稿。批准会物化业务记录，拒绝不修改任务正文。

  • 2选择 CSV 文件
  • 3校验并导入
  • 4归因数据展示区
按钮 / 控件作用注意事项
数据来源选择 GA4、GSC、表单或电话等来源类型。来源类型会参与重复文件判断。
选择文件 / 重新选择选择 CSV。支持 GA4/GSC 宽表或 observed_at、metric、value 标准列。
导入并校验校验字段后导入。未选择文件时禁用；格式错误不会部分导入。
12

复测报告

按固定工作流生成证据化叙述、质量检查、不可变版本与交付文档。

  • 2生成或推进报告版本
  • 3打开交付菜单
  • 4报告总览
  • 5证据索引
按钮 / 控件作用何时不可用或需注意
批次选择器选择要分析和交付的完成批次。报告只使用该批次冻结条件与证据。
生成新报告版本幂等推进叙述 → 质检 → 冻结 → 文档工作流。按钮文案会随状态变化；质检未通过时用于重新生成叙述。
交付打开文档与分享操作。正式文档要求最新叙述已批准且绑定质检通过。
生成 PDF + Word排队生成确定性 PDF 和 Word。前台等待超时只表示转后台，真实失败以服务端状态为准。
创建分享链接创建可设置有效期、可撤销的只读分享。系统只保存 token 哈希；链接应按敏感交付物管理。
总览查看管理摘要、证据等级、核心指标和平台表现。快审和正式基线口径会清晰标注。
口碑与建议查看 Agent 叙述、口碑信号、GEO 建议和运行轨迹。引用来源必须真实存在于回答证据。
数据明细查看问题矩阵、主题覆盖和基线差值。任一侧无成功回答的平台显示不可比。
诊断与整改查看报告冻结时的 finding 与任务。后续任务编辑不会回写旧快照。
证据索引按编号查看回答、网页、审计和引用信息。正文、PDF、Word 和 CSV 使用同一索引。
版本与分享查看快照 hash、文档状态和分享记录。快照不可修改；需要新内容时生成新版本。
运行详情展开 Agent 模型、尝试次数、Token、工具轨迹和错误。用于判断失败发生在模型、工具还是校验阶段。

先判断是权限、配置、外部 Provider、后台队列还是证据口径问题。

菜单或按钮不显示机构授权、角色权限、客户范围。由管理员在权限配置中修正；不要直接猜测 API 路由。
401 / 被退回登录会话是否过期、用户或机构是否停用。重新登录；管理员检查成员与机构状态。
403当前活动机构、页面权限、动作权限和客户范围。切到正确机构或申请最小所需权限。

批次长时间排队/采集中运行日志中的 capture-worker、租约、Provider 鉴权、限流和超时。不要手工把任务改成完成；让重试和租约清扫收敛，必要时按运行手册恢复 Worker。
批次“部分完成”证据中心的失败样本和 Provider 错误。保留真实失败；修好配置后创建新批次，不覆盖旧证据。
品牌率高但覆盖率低有效样本数、失败平台和回答覆盖率。品牌率只以成功回答为分母，必须和覆盖率/失败率一起解释。

指标与术语词典

所有比率均按代码中的确定性规则计算。

售前快审
每个平台每题 1 次的快速采集，不与正式基线直接比较。
正式基线
冻结完整范围与 Provider 契约，作为后续同条件复测锚点。
同条件复测
逐字段复制正式基线配置的新批次。
品牌提及率
成功回答中提及客户品牌的比例。
首位推荐率
成功回答中客户品牌位于第一推荐位置的比例。
官网引用率
来源可观测的成功回答中引用客户官网的比例。
品牌声量份额
客户品牌在已识别品牌提及中的相对份额。
平均提及位置
品牌出现样本中的平均位置；未提及时为 null。
重复一致性
同一问题有多次成功回答时，结果在重复采样间的一致程度。
回答覆盖率
计划样本中成功回答的比例。
失败率
计划样本中失败采集的比例，独立于品牌率。
证据等级
依据有效率和证据完整性给出的报告解释级别，不代表长期排名确定性。
Query Fan-out
Provider 为联网回答实际拆解的搜索查询；不可见时显示 unavailable。
冻结配置
客户、竞品、问题、平台、模型、协议、地区、重复次数、窗口和版本的完整快照。
Evidence ID
回答、网页、审计或联网搜索证据的不可混淆标识。
