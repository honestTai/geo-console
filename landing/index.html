01

监测品牌表现

围绕实际业务问题采样，查看品牌提及、明确推荐与引用来源。失败和未知保持原样，让数字有清楚的解释。

02 / WORKFLOW

一次完整的工作流程

阅读图文操作手册 ↗
  1. 01 / 建立范围

    从客户的问题开始

    整理品牌、竞品和资料，研究用户怎样提问，由成员确认监测范围。

  2. 02 / 留存基线

    采样真实回答

    按冻结配置采集，保存原文和可观察来源，了解当前表现。

  3. 03 / 推进整改

    带着证据改内容

    生成整改任务与文章草稿，结合知识资产进行质检、审核和人工发布。

  4. 04 / 复测交付

    对照变化，形成报告

    复用完整基线配置，比较符合条件的结果，交付在线报告、PDF 和 Word。

同配置复测减少采样条件差异，但不能单独证明整改与变化的因果关系，也不保证排名或收录。

FAQ

你可能关心。

是完整开源吗？可以商用吗？

是。项目自有源码采用 AGPL-3.0，完整功能源码包含在发行包中，允许依协议商业使用。没有单独保留的闭源核心。第三方组件遵循各自许可证。

可以先体验，再自行部署吗？

可以。请邮件联系 honest.tai@outlook.com 说明用途，我们私下沟通体验账号和登录方式。官方体验环境不开放自助注册。

使用开源版本还会产生哪些费用？

服务器、存储、域名以及模型和联网 API 可能收费，费用取决于供应商和使用量。部署、维护与定制属于可选服务。

AGPL 对修改版网络服务有什么要求？

修改版通过网络与用户交互时，应按 AGPL 第 13 条向这些用户显著提供对应源码的免费获取方式。分发还需遵守其他适用条款，具体以许可证全文为准。

AI 会直接替我发布文章吗？

不会。文章先形成草稿，通过质检和人工审核，由成员执行外部发布，再填写并复核回执。

能保证品牌排名或收录吗？

不能。ZZ Geo 帮助团队获得证据、做出判断并复测变化。AI 输出具有随机性，监测数据也不等同于消费端 App 的实际展示。
