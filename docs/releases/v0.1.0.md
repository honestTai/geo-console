# ZZ Geo v0.1.0

ZZ Geo 首个公开版本，用于 AI 搜索监测、证据核对、内容整改和复测报告交付。项目自有代码采用 AGPL-3.0-only，允许依协议商用，第三方组件保留原许可。

## 本版功能

- 客户管理与监测范围：品牌、竞品、问题候选及人工确认。
- 五渠道联网 API 采样：DeepSeek、Kimi、豆包火山方舟、通义千问 DashScope、元宝搜索源 + 混元合成。
- 回答证据、官网审计、差距诊断、整改任务和同配置复测。
- Agent 工作台、客户知识资产、文章版本、审核质检和人工发布回执。
- 在线报告、PDF/Word 交付，机构成员、角色与客户范围管理。
- 官网包含 20 页面模拟 Demo、图文手册、搜索地图与 llms.txt。

## 下载与启动

下载本页的 `zzgeo-v0.1.0.zip`（附 SHA-256），或 GitHub 自动生成的 Source code。两种都包含完整源码和 Docker 启动文件，**不是预构建镜像或离线安装包**。首次 Docker 构建需要网络下载依赖和 Chromium。

解压后在源码根目录运行：

```bash
# Linux / macOS / WSL
bash docker/quickstart/start.sh
```

```powershell
# Windows，Docker Desktop 使用 Linux 容器
powershell -ExecutionPolicy Bypass -File docker/quickstart/start.ps1
```

首次输入管理员邮箱，脚本生成独立随机密钥。默认只监听 localhost，访问 `http://localhost:8080/app/`；密码保存在 `.quickstart/secrets/admin_password`。请保留 `.quickstart/` 与 Docker 数据卷。

更多步骤见 [Docker 文档](https://github.com/honestTai/geo-console/blob/v0.1.0/docs/docker-quickstart.md)；[在线帮助](https://www.honesttai.com/help/)随官网更新，以标签内文档为本版本依据。
