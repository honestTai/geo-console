# 界面细节与文案

本次变更基准：`cda16814acd229863a38f3673fa3d98501a4fee3`。

## 布局

- Page 内提示与相邻表格、正文、操作行保留 16px 间距；审计工具栏与评分区单独分隔。
- 共享分页上下留出 16px，使用紧凑页码和固定 32px 点击区域。切换每页条数重置到首页，不重复触发旧页请求。客户列表删除后按服务端返回的有效页码刷新。
- 文章编辑抽屉左侧资料列和右侧表单均允许收缩，长问题、标题和引用不能超出各自列宽；两列之间保留间距与分隔线。只读项目默认打开文章预览。

## 文案

审阅范围包括客户首页和管理、建档、总览、监测、证据、官网审计、诊断、整改、归因、报告、文章、工作台、知识库、设置、成员、权限和日志页面，以及共用指标释义与网站检查说明。已清楚的字段名、错误状态和必要技术标签保留。

页面标题用业务名称；操作用具体动词；空状态说明当前缺少什么。删除重复功能介绍、夸张修饰及面向开发者的内部流程说明，例如“真实采集”“复测锚点”“证据白名单校验”。不把无法判断改成零分，不删费用提示、权限要求、采样可比性或引用与搜索来源的区别。

Agent v9 的文章写作增加自然行文要求：按实际主题组织内容，少用泛化营销词，不套“先看结论/核心洞察/未来展望”模板。证据、审批、字数上限与交付字段继续沿用原约束，历史文章、回答和冻结报告不批量重写。
