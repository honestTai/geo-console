# 云端 GEO 能力矩阵

工作台等待状态采用 ZZ GEO 专属 Z 描绘动画，覆盖启动、页面/详情、表格、按钮与下拉框，支持读屏和减少动态效果。保留短请求防闪烁与实际业务状态；文章详情读取失败提供重试，不以持续动画掩盖错误。见 `docs/ui-refinement.md`。

全工作台采用 GEOFlow 参考图的统一视觉比例和组件规范；整改中心改为“任务管理”布局，列表/已完成折叠/四项统计/三栏运行信息，操作在弹窗与详情抽屉中完成。界面不添加原系统不存在的“启动所有任务”、垃圾箱恢复或 Worker 在线指标。其他页面通过共享 Page、Shell、theme 和原语获得统一列表、表单、空态和导航布局。

2026-09 内容运营：文章列表支持独立审核/质检/发布状态、搜索、跨页选择与 Markdown 导出；文章版本、审核与质检结果留存，改稿/知识修订/策略变化后旧质检不可用于发布。客户知识资产独立管理资料、出处、有效期及批准历史。人工发布工作台提供渠道/账号、版本工单、执行人与计划、失败/结果不明、发布回执和复核。运营总览可直达权限范围内待办，业务反馈只消费导入记录。全站切为白色侧栏与蓝色浅色工作区。自动 CMS、浏览器代发、托管站点不在用户本轮选择范围；详见 `docs/content-operations.md`。

客户管理新增封档和两步确认删除：封档后只读；删除关闭项目、证据文件和分享访问，原始记录保留。未结束任务须先完成，新权限需明确授予。列表支持状态筛选和末页自动回退。界面细节及文案约定见 `docs/ui-refinement.md`，接口/发布边界见 `docs/customer-management.md`。

优化文章按真实问题、证据、受众与渠道决定类型、篇幅和结构，可为短答/页面局部补充或完整内容，不是固定通稿换企业名。新内容必须交付形式理由与篇幅依据，UI/PDF/Word 可见；允许无小节，不强制长文。仍需核实事实、授权、实际发布并同条件复测，不承诺 AI 引用；旧文章不自动重写。

客户可读闭环：共享指标释义/公式/实际分母、点名拆分、搜索与最终引用分别展示、逐题证据入口；新 PDF/Word 先问题/行动再公式与全文附录，保留 ZZGEO/客户、官网定位、批准任务/配对复测。文章增加用途/读者/具体渠道/依据/验收的可编辑计划，仅内容建议可生成。边界：旧报告不覆盖、缺资料明确披露、权限不扩大、不自动发布/付费重跑、不保证收录/排名。0026 和发布验收见 `docs/reader-report-workflow.md`。

机构管理分组新增“客户管理”：按名称/官网域名/行业搜索与分页，查看官网、建档状态和监测记录，按既有权限新建/编辑客户，具有客户工作台页面权限时可进入对应客户。只展示当前机构和成员有权访问的客户，不新增跨机构转移或删除证据能力。见 `docs/customer-management.md`。

2026-09 官网与额度恢复增量：客户可不填官网并在客户概览/建档补充编辑；无官网审计不适用、官网来源率为未知而非零；采样等待展示下一窗口，余额耗尽停止本批次该平台未执行采样并保留已有证据。官网审计支持 robots 声明/有限嵌套与压缩 XML Sitemap、逐项定位/建议/验收、源文件与受控截图详情、独立 ZZGEO HTML/PDF 报告；人工/Agent 同管线。最终 HTML/PDF/Word 有 ZZGEO 品牌和冻结客户信息。不是全站爬取、视觉模型诊断、全动态浏览器兼容性或收录/排名保证；旧证据不补写。见 `docs/website-audit-and-capture-recovery.md`。

新增完整回答辅助语义解读：按需生成全文概览/观点/分段、品牌维度情感、推荐理由与条件、比较、限制与歧义；支持原文高亮、历史、导出和 Python 离线标签评测。只读不付费，不影响正式排名；结构与引文校验不等于事实核验或模型准确率。实现和限制见 `docs/answer-analysis.md`。

借鉴 Elmo、Ansvisor、open-geo、GEO Optimizer 和 Semrush 的有价值工作流，但没有携带它们的营销站、计费、白标、海外 Provider 或额外基础设施。

V2 为唯一运行计算口径。完整实施与尚未验证的真实模型/标注集条件见 `docs/visibility-measurement-v2.md`。

## SQLite 桌面执行边界（2026-10-04）

当前桌面为 React → Tauri IPC → 本机 Node 业务引擎 → 新 SQLite 工作区。模型/搜索/采集/网站分析/指标/内容质检/报告/调度均在客户端；云端只鉴权、权限管理与账户私有快照存储。代码事实源：`apps/desktop/src/engine.ts`、`src-tauri/src/local_engine.rs`、`packages/core/src/sqlite.ts`、`apps/worker/src/api-service.ts` 和 `desktop-storage.ts`。独立指标、证据页面保留，不迁移旧数据库或业务数据。

会话/工具账本/等待状态/租约落 SQLite；MemorySaver 仅回合内使用。结果不确定的工具停止自动重放并要求成员核查。关闭客户端会停止本机执行；鉴权断网 fail-closed。哈希分块 + CAS 同步不自动合并冲突，设备主密钥不上传，新设备重配 Provider Key。桌面公开分享暂未接静态托管，会明确拒绝创建无效链接，PDF/Word 本地导出仍可用。

完整开发、恢复、测试和限制见 `docs/desktop-agent.md`。云端新部署显式使用 `compose.desktop-cloud.yaml`，不启动业务 Workers；其余服务器拓扑与 PostgreSQL 操作章节仅适用于旧版兼容部署，不代表新桌面执行位置。
