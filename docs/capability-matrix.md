## 成员生命周期与授权边界（2026-09-06）

成员页新增可分配角色/客户搜索分页、明确空范围、账号恢复和密码重置；只读成员不展示不可操作的新增表单。登录账号可验证当前密码后修改自己的密码。管理者不能创建、恢复、停用或重置权限/客户范围高于自己的账号，系统超管与自己的账号受保护。恢复不复活旧会话，密码重置撤销会话；角色改名不改变默认身份，机构上限收回/恢复不删除角色定义。已撤销的既有权限不会在 migration 中自动恢复。

Demo 默认机构权限配置与本地修复状态分开披露，详见 `rbac-demo-verification-2026-09-06.md`。
