# 云端 GEO 能力矩阵

| 模块 | 已实现能力 | 证据边界 |
| --- | --- | --- |
| 多客户项目 | 任意行业官网、地区、语言、别名、竞品、主题、Persona、问题人工确认；建档抓取最多 40 页（并发、24 小时内重试复用快照）；竞品候选在建档返回后由后台逐个联网核实（域名/行业），界面显示“核实中”并自动更新，未通过标“待确认”；竞品域名不能是客户官网或重复，确认时给出中文原因；确认范围沿用未变化问题/竞品的 ID，零修改保存不切断趋势；建档页“后台联网出题”生成待审批的问题研究草稿；监测范围可导出 JSON（含知识库引用）、导入后载入编辑器人工核对再保存为新版本 | 无默认客户或行业 Seed；核实结论只是提示，删留仍由成员决定；导入不带原项目行 id，跨机构或已归档的知识库引用在保存时去掉并提示数量 |
| 行业问题知识库 | 机构 + 行业问题复用、成员新增与归档、建档分析自动合并同业问题；确认监测范围（建档页/工作台候选表格）时可勾选把新问题回流到客户行业知识库并回填引用；JSON 导出/导入（按行业筛选，重复问题跳过） | Agent 新发现不自动写成共享知识，回流需成员勾选且有维护知识库权限；机构间不共享，导入只写当前机构 |
| 产品官网与帮助中心 | 根路径静态官网、与工作台同布局的响应式交互演示、登录入口跳转 `/app/`；`/help/` 提供可搜索的逐界面/逐按钮操作手册、脱敏编号截图和同源 A4 PDF，登录页、客户列表、工作台顶栏均可在新标签打开 | 演示与帮助截图隔离，不调用 API 或进入证据链；公开截图不得包含客户、凭据、邮箱、输入值或完整资源 ID |
| 五平台监测 | DeepSeek、Kimi、豆包、通义、元宝搜索源+混元合成；按真实批次状态、预期样本和 Capture 显示运行进度与日志；批次列表在停留期间自动刷新，Agent/周期监测创建的批次无需整页刷新即可出现；采集任务抛错或进程崩溃后批次仍会收敛为部分完成；周期监测到期创建失败在页面提示原因与连续失败次数，修改周期后下一次运行时间按新周期重算，到期时范围或平台配置变了自动改为新建基线 | API 口径不冒充 App；工作台不伪造运行日志；适配器升级后旧基线不能再复测 |
| 稳定性 | 快审 1 次，正式 3 次分时（超过 3 次在一天内平均分布），回答覆盖、重复一致性、失败率 | 快审与正式不可比较 |
| 品牌竞品 | 提及率、首位率、平均位置、声量份额、逐题竞品表现 | 由确定性代码计算 |
| 信源 | 来源可见性、引用、域名分类、新增/丢失来源、官网与竞品差距 | 未开放来源为不可用 |
| 官网审计 | HTTPS、robots、Sitemap、llms.txt、标题、Canonical、Schema、联系方式 | 抓取失败为证据不足 |
| HRouter Agent | 校验其他模型结果、诊断、整改、内容简报、口碑正负检测、GEO 建议、报告叙述、绑定版本的质量检查、按建议生成优化文章；问题研究与客户画像草稿可用 `web_search` 联网检索（每次运行最多 10 次）；模型与思考强度在平台设置中选择；草稿审批卡按用途分节展示（摘要、大纲、事实缺口、证据引用、正文、候选问题），首屏只放结论与概览标签 | 受限工具；联网搜索逐次落 `web_search_evidence`，只有成功记录可引用；口碑来源与回答证据逐条校验；人工批准（工作台自动模式除外）；草稿不按 JSON 键名平铺、不显示裸 UUID |
| AI 工作台 | 自然语言指令驱动 HRouter Agent 跑完整流程：确认问题集 → 建批次 → 等待采集 → 核验 → 官网审计 → 规则诊断 → 报告叙述/质检/冻结/PDF → 优化文章；“帮我出监测问题”让 Agent 联网研究买家问法后提交候选表格（问题/意图/主题/角色可改、可勾选、可增删，附来源与证据依据、候选竞品、知识库同步开关），确认后系统写入范围（建档页可直接跳入；问题不足时该指令置顶）；会话可关闭联网搜索，联网每回合 8 次/每会话 30 次；模型下拉按联网测试记录提示“未验证/失败”并可当场测试；会话可挂起等待后台任务并自动续跑；执行进度按步骤真实结果标记完成/失败，会话结束后仍在后台跑的文章显示“后台进行中”并由协调器收尾；“查看批次”跳到 AI 监测并选中该批次；自动批准可按会话开关 | 只操作当前客户项目；监测范围只能经成员确认写入，模型没有直接写范围的工具；联网搜索结果是不可信证据，连续未触发/失败后工具自身退化为“不可用”并退回官网与知识库出题；自动批准写审计并记录发起人；不发布、不改官网、不动原始证据 |
| 证据中心 | 按批次/平台浏览 AI 回答原文、来源、检索拆解与原始响应，CSV 导出；“联网搜索”分区列出 Agent 每次联网搜索的问题、状态、归纳文本、来源与实际检索词，草稿与候选表格里的 `[联网]` 引用可跳转定位 | 回答与联网记录写入后不可修改；未触发/失败的搜索照样展示但标明不可引用 |
| 优化文章 | 每条已批准 GEO 建议生成一篇 Markdown 草稿；列表/编辑/预览/状态/发布地址/重新生成；文章页在草稿等待协调器物化期间持续刷新 | 文章为可编辑草稿，不接 CMS，不自动发布；在途文章只按当前已批准叙述去重 |
| 整改 | 来源批次可选（默认最近完成批次）、优先级、负责人、截止时间、预期指标、验收：技术类任务重跑官网审计验收，其余发布 URL 重抓且地址须在客户官网域名下；“已验收”不能手工选择 | 不自动发布或改站；第三方页面不算验收证据 |
| 报告 | 售前快审、整改方案、周期复测不可变快照；展示口碑好坏、信息源和 GEO 建议；证据以 `[n]` 编号引用并附平台/问题/采样/时间/网址索引，可点击跳转证据中心；在线、PDF、Word、JSON、CSV、过期分享 | 已批准 Agent 叙述 + 通过质量检查后才冻结；保留失败率和黑盒声明；不显示裸 UUID |
| 报告工作流 | 一键启动、叙述审批后自动质检、质检审批通过后自动冻结与生成 PDF/Word、失败阶段可续跑；质检未通过时按钮改为“重新生成叙述”；PDF/Word 前台等待两分钟后转为后台提示并继续轮询，不报成失败 | 两次人工审批不自动绕过；同一叙述版本幂等冻结；不对同一份被 blocked 的叙述反复质检 |
| 归因 | GA4、GSC、表单、电话和业务台账 CSV 去重导入 | 并列展示，不自动声称因果 |
| 平台设置 | 五平台真实 Logo 导航、单平台配置、连接测试、各平台与 HRouter 模型下拉（从平台读取）、HRouter Agent 思考强度、“测试联网搜索”验证当前 GPT 模型经 HRouter 是否透传 `web_search`（结果按模型记住并列出）；平台设置导出/导入 JSON | 密钥不回显也不随配置导出，目标机构缺密钥的平台按停用导入；API 口径不冒充 App；HRouter 模型限定 GPT 系列 |
| 动态 RBAC 与机构安全 | 数据库驱动页面/API 资源目录、机构授权上限、自定义角色、用户多角色、全部/指定客户范围、唯一系统超管、机构切换与封禁/解封 | 未登记 API 默认拒绝；机构权限不能越权授予；活动机构和客户范围同时校验 |
| 列表分页 | 客户、机构、角色、用户、知识库、审计、运行日志、Agent、告警、报告、分享、归因与证据列表统一用同一分页条，默认每页 20；运行日志页码分页由日志服务返回总数 | 不在单页累积全部运行数据；报告冻结正文保持完整 |
| 工作台界面 | 按视图拆分的组件目录、antd 6 统一控件与分页、成功/失败 toast 与 Alert 反馈、首屏低密度信息架构、侧栏分组可折叠、页头面包屑导航（客户名返回列表、当前面板下拉切换）、统一间距刻度与 SectionTitle/FilterBar/KpiCard/IdChip/EvidenceRef 原语、页面标题唯一 | 主题固定 emerald 浅色系；手写控件不回流；装饰色仅品牌绿+中性灰，页内分组小节平铺；分页统一右下角 |
| 桌面客户端 | 面向全部用户的 Tauri 2 客户端、浏览器同步调试、应用内检查更新、签名更新包 | 更新私钥不进仓库；客户端只信任内置 GEO 公钥与 HTTPS 清单 |
| 运行日志 | 独立 Log Service、结构化批量采集、Trace ID、租户筛选、分页、CSV、自动刷新、90 天默认保留和手动清理 | 双重脱敏；不可保存回答/网页/raw；清理不触碰业务审计或证据 |
| 部署 | 根路径官网、`/app/` 同步工作台、Tauri 桌面客户端、API、Log Service、Capture/Agent/Report Worker、PostgreSQL、S3兼容存储、Caddy | PGlite 仅开发测试；日志服务只在内网 3020 |

借鉴 Elmo、Ansvisor、open-geo、GEO Optimizer 和 Semrush 的有价值工作流，但没有携带它们的营销站、计费、白标、海外 Provider 或额外基础设施。
