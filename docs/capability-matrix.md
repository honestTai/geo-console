# 云端 GEO 能力矩阵

| 模块 | 已实现能力 | 证据边界 |
| --- | --- | --- |
| 多客户项目 | 任意行业官网、地区、语言、别名、竞品、主题、Persona、问题人工确认 | 无默认客户或行业 Seed |
| 行业问题知识库 | 机构 + 行业问题复用、成员新增与归档、建档分析自动合并同业问题 | 不把 Agent 新发现自动写成共享知识；机构间不共享 |
| 产品官网 | 根路径静态官网、与工作台同布局的响应式交互演示、登录入口跳转 `/app/` | 演示数据隔离，不调用 API 或进入证据链 |
| 五平台监测 | DeepSeek、Kimi、豆包、通义、元宝搜索源+混元合成；按真实批次状态、预期样本和 Capture 显示运行进度与日志 | API 口径不冒充 App；工作台不伪造运行日志 |
| 稳定性 | 快审 1 次，正式 3 次分时，回答覆盖、重复一致性、失败率 | 快审与正式不可比较 |
| 品牌竞品 | 提及率、首位率、平均位置、声量份额、逐题竞品表现 | 由确定性代码计算 |
| 信源 | 来源可见性、引用、域名分类、新增/丢失来源、官网与竞品差距 | 未开放来源为不可用 |
| 官网审计 | HTTPS、robots、Sitemap、llms.txt、标题、Canonical、Schema、联系方式 | 抓取失败为证据不足 |
| Pi Agent | 校验其他模型结果、诊断、整改、内容简报、口碑正负检测、GEO 建议、报告叙述、绑定版本的质量检查、按建议生成优化文章；模型与思考强度在平台设置中选择 | 受限工具；口碑来源与回答证据逐条校验；人工批准（工作台自动模式除外） |
| AI 工作台 | 自然语言指令驱动内置 Agent 跑完整流程：确认问题集 → 建批次 → 等待采集 → 核验 → 官网审计 → 规则诊断 → 报告叙述/质检/冻结/PDF → 优化文章；会话可挂起等待后台任务并自动续跑；自动批准可按会话开关 | 只操作当前客户项目；自动批准写审计并记录发起人；不发布、不改官网、不动原始证据 |
| 优化文章 | 每条已批准 GEO 建议生成一篇 Markdown 草稿；列表/编辑/预览/状态/发布地址/重新生成 | 文章为可编辑草稿，不接 CMS，不自动发布 |
| 整改 | 优先级、负责人、截止时间、预期指标、验收、发布 URL 重抓 | 不自动发布或改站 |
| 报告 | 售前快审、整改方案、周期复测不可变快照；展示口碑好坏、信息源和 GEO 建议；证据以 `[n]` 编号引用并附平台/问题/采样/时间/网址索引，可点击跳转证据中心；在线、PDF、Word、JSON、CSV、过期分享 | 已批准 Agent 叙述 + 通过质量检查后才冻结；保留失败率和黑盒声明；不显示裸 UUID |
| 报告工作流 | 一键启动、叙述审批后自动质检、质检审批通过后自动冻结与生成 PDF/Word、失败阶段可续跑 | 两次人工审批不自动绕过；同一叙述版本幂等冻结 |
| 归因 | GA4、GSC、表单、电话和业务台账 CSV 去重导入 | 并列展示，不自动声称因果 |
| 平台设置 | 五平台真实 Logo 导航、单平台配置、连接测试、HRouter GPT 模型下拉（自动读取可用 GPT）与思考强度 | 密钥不回显，API 口径不冒充 App；模型限定 GPT 系列 |
| 动态 RBAC 与机构安全 | 数据库驱动页面/API 资源目录、机构授权上限、自定义角色、用户多角色、全部/指定客户范围、唯一系统超管、机构切换与封禁/解封 | 未登记 API 默认拒绝；机构权限不能越权授予；活动机构和客户范围同时校验 |
| 列表分页 | 客户、机构、角色、用户、知识库、审计、运行日志、Agent、告警、报告、分享、归因与证据列表分页 | 不在单页累积全部运行数据；报告冻结正文保持完整 |
| 工作台界面 | 按视图拆分的组件目录、antd 6 统一控件与分页、成功/失败 toast 与 Alert 反馈、首屏低密度信息架构、侧栏分组可折叠、统一间距刻度与 SectionTitle/FilterBar/KpiCard/IdChip/EvidenceRef 原语、页面标题唯一 | 主题固定 emerald 浅色系；手写控件不回流；装饰色仅品牌绿+中性灰，页内分组小节平铺；分页统一右下角 |
| 桌面客户端 | 面向全部用户的 Tauri 2 客户端、浏览器同步调试、应用内检查更新、签名更新包 | 更新私钥不进仓库；客户端只信任内置 GEO 公钥与 HTTPS 清单 |
| 运行日志 | 独立 Log Service、结构化批量采集、Trace ID、租户筛选、分页、CSV、自动刷新、90 天默认保留和手动清理 | 双重脱敏；不可保存回答/网页/raw；清理不触碰业务审计或证据 |
| 部署 | 根路径官网、`/app/` 同步工作台、Tauri 桌面客户端、API、Log Service、Capture/Agent/Report Worker、PostgreSQL、S3兼容存储、Caddy | PGlite 仅开发测试；日志服务只在内网 3020 |

借鉴 Elmo、Ansvisor、open-geo、GEO Optimizer 和 Semrush 的有价值工作流，但没有携带它们的营销站、计费、白标、海外 Provider 或额外基础设施。
